# 距离与控枪关卡设计企划书

> 层：design · 状态：active（装甲结构＋内凹墙面规范；审批与制作进度见[R7记录](../inspection/jiahao-range-hyper-r7-2026-10-03.md)） · 日期：2026-10-03。本文拥有本关的空间、画风与训练体验设计；当前实装及验收见 inspection。上位：[场景契约](../architecture/jiahao-trainer-scenes.md)、[模型制作流程](../organization/jiahao-model-modification-workflow.md)。共享运动、输入及枪械仍由原模块拥有。

## 设计目标

让玩家在安静、清晰、做工可信的靶场里感受距离对点射、连发与压枪的影响。首先解决用户指出的地板、墙壁、障碍物的廉价感；训练区的美术应帮助读靶，不靠杂物与高频纹理堆砌精度。

本关保留“距离与控枪”的身份与大厅入口。三角洲游戏内靶场作为功能参考，不宣称已取得原地图工程尺寸或完全一致的枪械后坐力。原游戏具体布局的复刻需要可追溯录像核对；本轮图纸是原创方案。

## 训练流程

1. 进入后先看到三个车道与简短说明，默认自由练习，玩家无需经过多层菜单。
2. 走入站位后提示标准距离；使用原有武器切换练10m连续控制、25m短连发、50m首发与点射。
3. 自由模式保持自动补靶，命中、击毁与弹着反馈清晰。J保留复位语义，复位目的地需显式提示，不悄悄移动玩家。
4. 后续计分练习由玩家主动开启：每车道一组，建议30秒；显示发射数、有效命中、头部命中、命中率、同一靶上的弹着分布。
5. 结束立即给本次结果与重试入口；不伪造三角洲的计分公式，也不宣称训练效果已获验证。

阶段定位建议：10m观察连续压枪的趋势；25m比较不同连发长度；50m比较点射与短连发的稳定性。它们是练习建议，不是强行改枪械参数实现的难度。

## 靶与反馈设计

第一阶段继续使用真实子弹射线与当前训练靶伤害链，避免“动画命中”和实际判定脱节。靶要稳定站立，击毁后在同位置补回，不主动攻击。不要用会走动的敌人当静态靶却仍把距离当常量。

弹着纸与复盘屏属于第二阶段功能：纸面可见撞击标记需要真实射线落点；头胸命中指标来自实际命中区。分布范围应记录有效样本数、枪型、射击模式和站位，不能把漏靶样本丢掉后称“完整弹着分布”。漏靶计入射击总数，弹着图若只显示落在靶上的样本必须明确说明。

反馈排序：靶轮廓 > 命中确认 > 距离 > 训练文字 > 装饰。靶后禁止直射灯与大字；灯具位于上方。近靶背板不能遮挡其他车道远靶。音响／陪伴站放后勤区而非射击线旁。

长边7×8+4=60m，端跨通过Blender裁切封口形成。完整柱共享边去重；后墙抽取平板复用，入口留4×3.60m门洞。玻璃、发光灯片、白线、靶背板和简单接口在Blender制作或复用。凹墙向建筑外侧伸出，不侵入24m净宽。

图纸与新部件参考须明确批准后才花credit，外观认可不自动等于付费生成批准。首先仅验证一个墙柱代表件的拆分、补切面、法线、UV和近景质感，再扩展其他部件；付费参考不得使用已被否定的旧母件图。

生成候选沿用已认可R3配方：单张获批主参考、Gen-2.5-High、Raw、quality_override=1000000、GLB；它是高密度母版，不是游戏面数承诺。实际额度、可用参数与扣费以调用结果为准。

下载原始结果后在Blender检查平面、倒角、检修槽与基座，保留可编辑、贴图打包的.blend。对运行副本另做保形优化，目标每个掩体≤3500三角面，近景若受损则按实际效果调整预算；不得把百万面母版六份直接塞进游戏。仍不合格时先诊断图纸、网格与材质原因，不自动重生成。当前生成是否完成、实际花费和近景验收由inspection记录。

所有新三维模块在Blender制作，保留可编辑.blend及导出GLB。当前风格先试同一12×16×9m局部样段，明确不是把50m靶道缩短成16m。样段可证明建模与材料的基本可行性，不能代替完整关卡性能或玩法验收。

目标预算：本关新增运行资源≤20MB、可见场景初始目标≤200k三角面（需LOD/实例化实测）、基础材质≤12种、尽量复用模块；这些是设计预算，实测超出需列出原因。不为了高“精度”铺4K贴图。概念图、渲染与.blend不随运行包输出；导出只包含确实用到的GLB及必要资源。

碰撞按连续地面、墙体与掩体简化，不能让每块地板接缝变成碰撞台阶。细节网格与碰撞职责分开。引擎材质、阴影、法线和曝光需要实际Godot视角复核，不以Blender离线渲染冒充实时结果。

## 视觉验收标准

- 同曝光的正常玩家视角里，地板缝清晰但不抢靶；远处没有摩尔纹、闪烁或强棋盘感。
- 墙、地、掩体分别具有可辨识的粗糙度与轮廓；不靠统一灰色或强高光表现全部材质。
- 掩体底座接地、倒角尺度一致，近景没有波浪面、纹理拉伸、悬浮与穿插。
- 从三个站位及横移位置，对应靶头胸轮廓可见；镜瞄不会被环境装饰遮住。
- 实际Blender打开最终.blend的界面截图、实际Godot画面、运行与包体记录分开保留。
- 用户的美术判断决定是否推广；机器导入通过不代表已满足用户审美。
