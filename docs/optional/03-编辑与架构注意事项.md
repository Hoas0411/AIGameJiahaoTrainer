# 编辑入口与架构边界
> 源码为事实 owner，原契约为 upstream/architecture/jiahao-trainer-scenes.md；旧契约表中已退役路径不保证存在。

|修改内容|当前入口|需保护|
|---|---|---|
|会话/切关/结算|game/scripts/main.gd、scenes/main.tscn|历史唯一写入者、换关恢复输入|
|课程集合|scripts/course_registry.gd|稳定ID，入口/陪伴/导出一致|
|运动/QE|scripts/player.gd、motion_profile.gd、resources/motion_baseline.tres|所有关卡共用，不创建私有参数副本|
|枪械/瞄具|scripts/weapon.gd、weapon_profile.gd、resources/weapons、scenes/weapons|普通持枪/镜瞄/侧瞄都回查，手、枪口、镭射一致|
|专项行为|scripts/training、scripts/levels + 对应scenes/levels|关卡不要改共享玩家/武器|
|对照与训练证据|scripts/training/training_session_context.gd、training_comparison.gd|只读取原配置和原历史；不同参数/站位不能假装可比|
|模型|source_art中的.blend → assets/resources中的GLB|保持骨骼名、尺度、轴向、材质和碰撞接口|
|麦小鼠|scripts/companion*.gd、bubble_ui.gd、dialogue_frame.gd|成绩不由AI改写；记忆提议需确认；旧请求取消|
|模型服务|companion-service/server.mjs及相关模块|仅回环；密钥不入PCK；云端内容外发需明确配置|
|UI|scripts/minimal_hud.gd、approved_ui.gd、interface.gd、ui/approved|不增加重复主题/成绩存储|

表内未以game/开头的路径相对game。user:// 保存个人设置、按键、运动、聊天和训练历史；包不包含原用户数据。新机器默认值与作者个人手感配置可能不同，不要猜测或复制私人存档。测试使用包内独立环境，不影响原电脑存档。

companion-service/config.example.json 是示例；启用 AI 时复制到 config.local.json 并自行填写模型/接口，不能将“开关打开”说成模型已连接。训练离线可用；语音需 Whisper 与模型；权重未打包，基础训练不因此缺失。包内 Node 用于服务；Blender 是建模工具，须安装在 D 盘并由开发者指定。Godot AI 插件已保留但不同机器上的 MCP 连接需重新配置，不能保证原连接可迁移。

source_art仅保留运行资源对应的必要编辑源；.blend源已保留，自动备份与嵌套Godot缓存未打包；历史作者脚本已从精简包移除，当前工具仅在本包工作。当前启动和导出只使用 tools/portable.ps1，本包不再附带旧 tools/package_companion_actions.py。

精简包的唯一模型源映射见根目录 delivery/model-source-map.json；原文提到的其他历史候选或研究证据未随包提供，不是当前运行缺失。
