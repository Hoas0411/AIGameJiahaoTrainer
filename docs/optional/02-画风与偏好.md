# 用户画风偏好与已知反馈
> 是已有用户记录的交接投影，不是本次新设计，也不代表所有关卡已获认可。后续用户明确反馈优先。原始依据位于 upstream/design、upstream/organization、upstream/inspection；活动场景和 source_art 是当前外观的检查入口。

## 三维训练环境
用户有建筑设计背景，重视空间、动线、结构、氛围和实际体验。共同要求是可信的比例、真实接缝/厚度/制造逻辑、清晰的材质与光影、主体可读性；讨厌廉价方块堆砌、波浪平面、塑料高光、拉伸模型、悬浮与穿插、没有实物依据的随机装饰。

距离与控枪：2026-10-02 已明确认可装甲结构方向，要求去掉机械臂，将设备舱改普通墙或封闭内凹墙。冷中灰哑光涂层金属、石墨接缝、裸金属五金；平齐细槽地面、白色分道线不发光。早期暖白“极简建筑A”、漫画工业B、Portal风实验室C属于历史候选，不能仅看文档标题就恢复旧方案。详见 upstream/design/jiahao-distance-control-design.md；它也含设计提案，当前是否实装须查场景。

AWM：优先保护当前对称端墙、原有构图与已校准枪模，维持结构比例与材质匹配；黑金二版曾暂缓，不能自动切换。对应源：game/source_art/awm_endwall_symmetry_20261005、awm_delta_optic_20261005。枪体不得靠非等比缩放凑屏幕占比。

架门缝：当前 C1 系列 Blender 建模、加宽门柱、敌人面朝玩家，延续现在实装外观。早期概念与r13等源版本均有保留，但不能按源目录日期擅自覆盖实装；先沿 runtime.tscn 的 GLB 引用定位。

基地：以 circular_lobby_fit 的当前实例为基线；源里五种大厅、呼吸感和顶棚研究都是历史/候选材料，不能视为用户选定风格。

## HUD 与麦小鼠
极简 HUD：保护中心瞄准视野；技能/弹药/状态区克制、清楚，别增加一圈常驻调试文字。极简结构获批记录见 upstream/design/2026-09-15-游玩HUD与技能特效-极简结构修订-迭代002.md，实际实现看 game/scripts/minimal_hud.gd、game/ui/approved。

麦小鼠：原创鼠耳角色，保留可见表情、独立跟随与训练反馈，不挡玩家和子弹。对话使用米白圆钝框体、七表情抱框角色，模型表情与UI同步；完整回复和段落不能被固定小框裁掉。实体入镜且空间足够时世界气泡，否则固定右侧回复框，避免遮挡瞄准与弹药栏。具体已实装契约见 upstream/architecture/jiahao-trainer-scenes.md。

不要把其他游戏（例如剁手节拍）的木牌/旧漆金属/观众画风搬进嘉豪训练器；上游资料库混有其他项目，按专题选择。

## 看图与制作
新三维制作先设计图，再Blender可编辑源，导出GLB后在真实Godot相机里复核。同分辨率、FOV、曝光和机位保留改前改后，检查转折、材质、接地、手部握持和动态动作。功能通过不能替代画面检查，AI自检不能代签用户满意。执行规则只由 ../boundaries/画面质量规范.md 拥有。

精简包的唯一模型源映射见根目录 delivery/model-source-map.json；原文提到的其他历史候选或研究证据未随包提供，不是当前运行缺失。
