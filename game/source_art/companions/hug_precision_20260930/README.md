# 麦小鼠托抱精修 · 2026-09-30

状态：**用户验收严重不合格，已拒收（2026-09-30）**。手部与持枪手不一致；麦小鼠近景清晰度和形态不合格；抱起动作不自然；亲脸没有接触。下面的旧机器记录仅保留作诊断，不代表外观或动作达标。返工位于 `../hug_rework_20260930/`，不得把本版标作合格交付。本文不修改项目长期规则。

## 设计与源文件

- 依据用户本次批准的三格图：`../hug_20260930/design.png`（REACH / HOLD / CHEEK）。
- `hug_interaction.blend`：最终可编辑总工程，贴图已打包，默认第 61 帧托抱；含麦小鼠、14 骨骼与玩家双手、袖口、护指、缝线等 92 个可编辑部件。
- `mouse_hug.blend`：单独的角色骨骼与三个体积修正形态键源文件。
- 模型在 Blender 中制作、修正与导出；没有调用 Hyper3D、没有新付费生成，也没有运行时生成网格。
- 鼠模型沿用既有开心版的 23,485 顶点、38,752 三角面、UV 与 2048 贴图，不重生成脸、不减面。静止网格最大误差约 `9.22e-8`。
- 双手分别为 31,750 / 32,742 顶点；每手四指及对向拇指，左右手镜像手性，掌指为闭合连续网格。左右手分别批处理为六材质表面，保留独立进出路径。

## 运行与操作

当前开发入口：[launch_game.cmd](D:/Codex/项目/AIgame/apps/jiahao-trainer/launch_game.cmd)，不是旧 builds 成品。开启麦小鼠并靠近到 2.2 米内，默认 **O** 抱起 / 放下，**P** 亲脸。按键若已占用，界面显示实际自动选定的键位。

消费者仅为 `scripts/companion_hug.gd`。角色动作在 Blender 的 `HugSequence` 中；双手进入/撤出轨迹由该脚本的 `support_pose` 控制。左手在膝盖收起后从侧下方进入，避免穿过腿部。正常站立模型、玩家持枪模型、共享玩家/武器核心均不替换。

拥抱时租用战斗/武器显示状态；放下恢复原状态，新场景不恢复旧租约覆盖新场景状态。继续使用既有短布料摩擦音，本次未添加或声称完成麦小鼠参考音色匹配。

## 验证证据与边界

- `geometry_validation.json`：双手无边界边、无非流形边，全部坐标有限；托抱姿态检查全部手部顶点未发现进入角色内部；72 个过渡姿态按每 24 顶点抽检、三方向射线复核，没有检测到超过 1 mm 的手部内部点。它是离线抽样证据，不是任意新姿态绝不穿模的数学保证。
